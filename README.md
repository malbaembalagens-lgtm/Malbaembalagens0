# MALBA Sistema 2026

Sistema de gestão operacional da MALBA Embalagens.

## Deploy

Site estático single-file. Deploy direto no Vercel sem build.

- **Banco de dados**: Supabase (não muda nada na migração)
- **Realtime**: Supabase Realtime (já configurado)
- **Login admin**: admin@malba.com.br / admin123

## Como atualizar

1. Substitua `index.html` pela nova versão
2. Faça commit no Git (ou arraste no painel do Vercel)
3. Deploy automático em ~30 segundos
